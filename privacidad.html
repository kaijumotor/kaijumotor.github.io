Política de privacidad

Última actualización: 25 de octubre de 2026

Esta política explica cómo AutoReels, la herramienta interna de Kaiju Motor, trata los datos cuando se conecta a cuentas de YouTube, Instagram y TikTok.

Quién la usa

AutoReels la usa únicamente el titular de Kaiju Motor para gestionar sus propias cuentas. No es un servicio abierto al público ni se ofrece a terceros.

Qué datos se usan

Con el permiso del titular de la cuenta, AutoReels accede a: los datos básicos del perfil (nombre de usuario e identificador), las publicaciones y sus estadísticas (reproducciones, me gusta, comentarios, alcance) y los comentarios recibidos, para poder publicar vídeos, ver cómo funcionan y responder.

Dónde se guardan

Los tokens de acceso y las estadísticas se guardan solo en el ordenador del titular. No se envían a servidores de terceros, no se venden y no se comparten con nadie.

Cuánto tiempo

Los datos se conservan mientras la cuenta siga conectada. El titular puede desconectar AutoReels en cualquier momento desde la configuración de seguridad de Google, Instagram o TikTok, y borrar los datos locales.

Uso de datos de Google

El uso de la información recibida de las APIs de Google se ajusta a la Política de Datos de Usuario de los Servicios de API de Google, incluidos los requisitos de uso limitado. AutoReels usa los servicios de API de YouTube; consulta también la Política de privacidad de Google.

Contacto

Para cualquier duda o para pedir el borrado de datos: kaijumotor@gmail.com
